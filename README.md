# Hospital Management System (FinalPaper)
A core Object-Oriented Java application designed to manage hospital operations, including patients, doctors, appointments, and application workflows.

---

## 📂 Repository Structure

```text
FinalPaper/
│
├── HospitalApp.java     # Main execution entry point for the application
├── Patient.java         # Patient entity and data management class
├── Doctor.java          # Doctor entity and profile management class
└── Appointment.java     # Appointment scheduling and relation handling class
```

🚀 Key Features
1. Object-Oriented Design (OOP): Encapsulates core hospital entities (Patient, Doctor, Appointment) into distinct, reusable classes.
2. Relationship Management: Handles the linkage between patients, assigned doctors, and scheduled appointments.
3. Java Application Flow: Driven through a structured execution loop managed by HospitalApp.java.

💻 Getting Started & Execution
Ensure you have the Java Development Kit (JDK) installed on your machine.

🖥️ Windows & Linux (Terminal / Command Prompt)
Clone the repository:

```Bash
git clone [https://github.com/dragon-udfly/FinalPaper.git](https://github.com/dragon-udfly/FinalPaper.git)
```
Navigate into the directory:

```Bash
cd FinalPaper
```
Compile all Java files:

```Bash
javac *.java
```
Run the main application:

```Bash
java HospitalApp
```
